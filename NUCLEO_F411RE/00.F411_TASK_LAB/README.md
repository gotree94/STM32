## 진행 방식

- **한 번에 한 단계만** 진행한다.
- 각 단계는 `목표 → 준비물/배선 → 설정 → 코드 → 빌드/플래시 → 보드 확인 → 체크리스트` 순서로 읽는다.
- **보드에서 확인이 끝난 뒤에만** 다음 단계 파일을 연다.
- 센서 모델, 핀, 주기, 정확도 같은 결정은 해당 단계에서 함께 정한다.
  미리 확정하지 않은 가정은 문서에 적지 않는다.

## 다음 행동

1. `STEP00_환경확인.md`를 훑고 시리얼 포트를 확인한다.
2. `STEP03_온습도_보정.md`의 배선대로 DHT11/DHT22를 PA4에 연결한다.
3. DATA-PA4에 4.7 kΩ ~ 10 kΩ 풀업이 있는지 확인한다. (모듈 내장이면 생략)
4. 현재 펌웨어를 빌드/플래시한다.
5. LD2가 0.5초마다 깜빡이고, 시리얼에 1초마다 `D,...`, 2초마다 `E,...`가 나오는지 확인한다.
6. `D`의 보정 전/후 거리와 `delta_mm`을 비교한다.
7. `E`의 온도/습도와 `sound_speed_x10`이 상식적인지 확인한다.
8. 결과(성공 또는 증상)를 알려주면 다음 단계로 진행한다.

> STEP02부터 LED는 무음으로 점멸한다. `LED ON` / `LED OFF` UART 출력은
> 거리 CSV를 깨끗하게 유지하려고 제거했다.
