# STM32F411 GPIO: ODR과 BSRR 분리와 원자적 연산

> **핵심**: BSRR이 존재하는 이유는 GPIO 핀 하나를 **읽기-수정-쓰기(RMW) 없이 원자적으로** 바꾸기 위해서이다.

---

## 1. ODR만 있을 때의 문제: Read-Modify-Write

ODR은 16비트 레지스터 하나에 모든 핀의 출력 상태가 들어 있다. 핀 하나만 바꾸려면 다음과 같이 쓴다.

```c
GPIOA->ODR |= (1 << 5);     // PA5 set
GPIOA->ODR &= ~(1 << 5);    // PA5 clear
```

이 한 줄은 CPU 입장에서 실제로는 세 단계이다.

```asm
LDR  r1, [ODR]      ; ① 읽기
ORR  r1, r1, #0x20  ; ② 수정
STR  r1, [ODR]      ; ③ 쓰기
```

①과 ③ 사이에 인터럽트가 들어오면 문제가 생긴다.

| 시점 | 메인 코드 | ISR |
|---|---|---|
| ① | ODR 읽음 (0x0000) | |
| (인터럽트 발생) | | `ODR \|= (1<<0)` → ODR = 0x0001 |
| ③ | 0x0020을 씀 | |
| 결과 | **ODR = 0x0020, PA0 변경이 사라짐** | |

메인 코드가 들고 있던 옛날 값(0x0000)으로 ODR 전체를 덮어쓰기 때문에, ISR이 바꾼 PA0이 유실된다. 이것이 전형적인 **lost update** 문제이다. RTOS의 다른 태스크, DMA, 다른 ISR 사이에서도 똑같이 발생한다.

---

## 2. BSRR의 해법: Write-Only, 비트 단위 동작

BSRR(Bit Set/Reset Register)은 32비트 **쓰기 전용** 레지스터이다.

```
bit 31..16 : BR15..BR0  (1을 쓰면 해당 핀 Reset → 0)
bit 15..0  : BS15..BS0  (1을 쓰면 해당 핀 Set → 1)
```

```c
GPIOA->BSRR = (1 << 5);          // PA5 set
GPIOA->BSRR = (1 << (5 + 16));   // PA5 clear
```

동작 규칙: **"1을 쓴 비트만 효과가 있고, 0을 쓴 비트는 무시"**

- 읽기 단계가 없음 → 옛날 값을 들고 있을 일이 없음
- 단일 `STR` 명령 하나 = 버스 상에서 한 번의 쓰기 → 중간에 끼어들 틈이 없음
- 건드리지 않은 핀은 0을 썼으므로 영향 없음 → 다른 핀 상태 보존

즉 "내가 바꾸고 싶은 비트만 지정하는" 구조이므로, 다른 컨텍스트가 같은 포트의 다른 핀을 바꿔도 서로 간섭하지 않는다.

---

## 3. 왜 "분리"되어 있어야 하는가

ODR은 "현재 상태 전체"를 표현하는 레지스터이고, BSRR은 "변경 요청(command)"을 표현하는 레지스터이다. 역할이 다르다.

- **ODR**: 상태 값 저장 (읽고 쓸 수 있지만 RMW 위험)
- **BSRR**: 상태 변경 명령 (쓰기 전용, 원자적)

BSRR에 쓴 결과가 ODR에 반영되는 구조이다. 읽을 때는 ODR로 현재 값을 확인하고, 바꿀 때는 BSRR을 쓰는 식으로 쓰기 경로와 읽기 경로를 분리하면 RMW 자체가 필요 없어진다.

---

## 4. 주의할 점

### ① Set과 Reset을 동시에 쓰면 Set이 우선
같은 핀의 BSx와 BRx를 동시에 1로 쓰면 Set이 이긴다. (참조 매뉴얼에 명시된 동작)

### ② 여러 핀을 동시에 원자적으로 변경 가능
```c
// PA0, PA1 set 하면서 동시에 PA2, PA3 clear
GPIOA->BSRR = (1<<0) | (1<<1) | (1<<(2+16)) | (1<<(3+16));
```
32비트 한 번의 쓰기이므로 네 핀이 같은 순간에 바뀐다. (ODR로 하면 한 번에 쓸 수는 있지만, 그 전에 읽어야 하므로 RMW 문제가 따라온다.)

### ③ ODR 전체를 직접 쓰는 것은 괜찮은 경우도 있음
`GPIOA->ODR = 0x1234;` 처럼 16비트 전체를 정해진 값으로 한 번에 쓰는 것은 RMW가 아니므로 원자적이다. 문제는 `|=`, `&=` 같은 **부분 수정**이다.

### ④ 비트 밴딩과의 비교
Cortex-M4는 비트 밴딩 영역으로도 단일 비트 원자 접근이 가능하다. 다만 이식성이 떨어지므로, BSRR이 가장 표준적이고 빠른 방법이다.

---

## 5. 정리

| 항목 | ODR `\|=` / `&=` | BSRR |
|---|---|---|
| 내부 동작 | Read → Modify → Write | Write only |
| 인터럽트 중 안전성 | 위험 (lost update) | 안전 |
| 다른 핀 영향 | 옛날 값으로 덮어쓸 수 있음 | 0 쓴 비트는 무시되어 영향 없음 |
| 다중 핀 동시 변경 | RMW 위험 있음 | 한 번의 쓰기로 가능 |
| Set/Clear 표현 | 비트 연산으로 계산 | 상위/하위 16비트로 분리 |

**한 줄 요약**: *"읽기를 없애면 원자성은 공짜로 따라온다"* — 이것이 BSRR 설계의 핵심 아이디어이다.

> 💡 **교육 팁**: 위의 ISR 간섭 시나리오 표를 어셈블리 3단계(LDR/ORR/STR)와 함께 보여 주면 학생들이 가장 직관적으로 이해한다.
